# 2D Battle Royale

A fast-paced 2D Battle Royale game built entirely from scratch using Java and JavaFX. The project focuses on game development fundamentals, real-time rendering, multithreading, collision detection, and object-oriented design.

### Technologies Used
* Java
* JavaFX
* Multithreading
* Object-Oriented Programming (OOP)
